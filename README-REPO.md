# SOMA v3 — 一间屋子里的小蓝

一个跑在手机上的「会过日子」的 3D 角色实验：**C++ 物理身体 + 60 Hz 矩阵脊髓 + 异步大模型大脑**。
她自己在屋里走动、吃饭、睡觉、上厕所、无聊了出门站一会儿；你可以在面板上调她的激素、摸她的头。

## 它是什么

- **身体**：C++ 自己写的 18 节点人形 + 足底捕获/ZMP，60 Hz 跑，三角肌/腿长/步态公式都是量过的。
- **脊髓**：58 维矩阵（60 Hz 增量模型 + 在线 LMS），从她自己的身体数据里拟合出来。
- **大脑**：快脑（<3 s 给一个意图）+ 慢脑（独立会话里规划），都只输出 JSON，不直接控制关节。
- **习惯**：13 个动作、12 个地点、驱力（饿/渴/困/累/无聊/膀胱），干了给奖励、憋着会难受。
- **触觉**：16 个感受点（掌心/指节/前臂/肩/胸/腰/膝/胫/脚底/头/颈），撞上真的会疼。
- **场景**：客厅 + 北厢三间房 + 门外走廊，家具用的是 Poly Haven 的 CC0 模型（`web/models/ph/`）。

## 跑起来

```bash
# 1) 编译身体（需要 g++）
cd cpp && g++ -O2 -std=c++17 -o soma3d main.cpp && cd ..

# 2) 起服务（默认 8125）
./restart.sh

# 3) 浏览器打开
#    http://127.0.0.1:8125/
```

浏览器里点一下「进 去」，就能看到她。左下摇杆走、拖动转视角、右上角菜单调画质/镜头/声带。

## 目录

```
cpp/        身体、脊髓、激素、触觉、寻路（纯 C++，无第三方依赖）
assets/     脊髓权重、动作剪辑、房间碰撞盒、身体参数
web/        three.js 场景、VRM 角色、面板、语音
brain/      习惯层（谁在什么时候想做什么）
tools/      训练与调试脚本（mocap 转换、自身数据拟合）
```
